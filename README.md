# CHI.LOG

개인적으로 필요한 것들을 기록하고 서비스하는 다용도 개인 페이지입니다.

## 수정하기

- `index.html`: 소개, 프로젝트, 기록, 링크 내용
- `styles.css`: 색상과 화면 디자인
- `script.js`: 다크 모드와 작은 상호작용

## GitHub Pages 배포

1. 변경 사항을 `main` 브랜치에 push합니다.
2. 저장소의 **Settings → Pages**에서 Source를 **GitHub Actions**로 선택합니다.
3. Actions의 `Deploy static site to Pages` 작업이 끝나면 공개 주소가 생성됩니다.

현재 저장소 기준 예상 주소: `https://clcl616.github.io/chi-log/`
